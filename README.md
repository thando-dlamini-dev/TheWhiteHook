# 🍋 CITRUS Co.

> A fictional wellness supplement brand and landing page, built to showcase front-end design and ecommerce UI skills.

![CITRUS Banner](./public/assets/banner.png)

---

## 📌 Overview

**CITRUS** is a concept ecommerce product landing page designed as a portfolio piece. It simulates a real-world supplement brand with a fully designed storefront — from hero section to checkout CTA — demonstrating UI/UX, branding, and front-end development skills.

This is **not a real product**. All branding, copy, customer reviews, and product claims are fictional and created solely for demonstration purposes.

---

## ✨ Features

- 🛍️ Full product landing page with ecommerce UI patterns
- 💊 Realistic supplement branding (CITRUS — Vitamin C, D3 & Zinc formula)
- 📱 Fully responsive — mobile, tablet, and desktop
- 🎨 Custom label design used as 3D render texture
- ⚡ Smooth scroll animations and micro-interactions
- 🗣️ Testimonials, FAQ accordion, and newsletter signup section
